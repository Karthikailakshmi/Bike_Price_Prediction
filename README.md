# Bike Price Prediction

A simple Machine Learning project to predict bike prices using **Linear Regression**.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## Features

* Data analysis
* Data visualization
* Linear Regression
* Bike price prediction

## Files

* `bike_price_prediction.ipynb` - Project notebook
* `bike_sales_india.csv` - Dataset
